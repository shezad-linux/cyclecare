# UI Token Map

## Color Roles

- `bgCanvas`: warm ivory
- `bgSurface`: soft shell
- `brandPrimary`: mulberry
- `brandAccent`: coral
- `successTone`: sage
- `textPrimary`: deep ink
- `textSecondary`: muted plum
- `statePeriod`: rose
- `stateOvulation`: lake blue
- `stateFertile`: mint

## Typography

- Editorial-style display headlines
- Clean sans body copy
- Compact labels for chips and calendar annotations

## Spacing And Shape

- Base spacing scale: 4, 8, 12, 16, 24, 32
- Corner system: 12, 20, 28
- Cards use soft elevation and large radii
