# Reminder Sound Sources

The bundled reminder sounds in [app/src/main/res/raw](/Users/shezad/Documents/period/app/src/main/res/raw) are sourced from the GitHub repository [lavenderdotpet/CC0-Public-Domain-Sounds](https://github.com/lavenderdotpet/CC0-Public-Domain-Sounds), which publishes these assets under [CC0 1.0](https://github.com/lavenderdotpet/CC0-Public-Domain-Sounds/blob/main/LICENSE).

Current asset mapping:

- `gentle_bell.ogg` -> [`100-CC0-SFX/bell_01.ogg`](https://github.com/lavenderdotpet/CC0-Public-Domain-Sounds/blob/main/100-CC0-SFX/bell_01.ogg)
- `soft_chime.ogg` -> [`kenney_interfacesounds/Audio/confirmation_002.ogg`](https://github.com/lavenderdotpet/CC0-Public-Domain-Sounds/blob/main/kenney_interfacesounds/Audio/confirmation_002.ogg)
- `water_drop.ogg` -> [`kenney_interfacesounds/Audio/drop_004.ogg`](https://github.com/lavenderdotpet/CC0-Public-Domain-Sounds/blob/main/kenney_interfacesounds/Audio/drop_004.ogg)

Selection criteria:

- Short notification-style duration suitable for reminders.
- Calm interface-oriented timbre instead of alarm-like audio.
- Clear license and stable GitHub-hosted source path.
