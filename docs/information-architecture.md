# Information Architecture And Flows

## Primary Navigation

- Home
- Calendar
- Log
- Insights
- Settings

## Secondary Routes

- Onboarding
- Privacy Lock
- Export Report

## Critical User Flows

### First Launch

1. Welcome
2. Age band and cycle setup
3. Goals and reminder preference
4. Privacy preference
5. Land on dashboard with first prediction

### Daily Logging

1. Open Log tab
2. Pick mood, pain, energy, discharge
3. Add medication or notes
4. Save
5. Reflect changes on dashboard and insights

### Insights And Export

1. Open Insights
2. Review the advanced overview with cycle variability, trend charts, and symptom-pattern summaries
3. Open cycle-trends or symptom-pattern detail routes when more context is needed
4. Open Export from Settings
5. Generate and share a local report

### Privacy Lock

1. Open settings
2. Enable app lock
3. Create PIN
4. Confirm hidden notification preview choice
