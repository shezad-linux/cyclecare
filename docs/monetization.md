# Free With Ads Policy

## Product Position

- CycleCare ships as a fully free Android app
- All current features are available by default
- Ads may appear in non-blocking surfaces
- No paid-access systems are part of the product

## Included Capabilities

- Core cycle tracking and daily symptom logging
- Local predictions and detailed insights
- Styled local exports
- Privacy lock and notification privacy controls

## Product Guardrails

- No gated feature prompts or paid-access surfaces
- Ad surfaces must not block tracking, reminders, privacy, or export workflows
- Ad SDKs must not receive cycle dates, symptoms, notes, profile details, or exported reports
- Google UMP consent must be configured for the production AdMob app ID before launch
- New features should default to the free product model unless product direction changes explicitly
